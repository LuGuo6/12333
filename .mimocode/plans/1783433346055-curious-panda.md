# 玄戒O1 全合一伪装模块

## 目标

创建一个 KPM 模块 `xuanjie_o1/`，加载后将设备伪装为小米玄戒O1：
- **CPU**: 玄戒O1（ARM Cortex-X925 + A725，8核）
- **GPU**: ARM Immortalis-G925
- **内核**: 6.6.77-android15

无论原设备是骁龙、天玑还是其他平台。

## 伪造数据来源

| 项目 | 数据 | 来源 |
|------|------|------|
| CPU | 8核 cpuinfo（2×0xd80 + 6×0xd87） | `cpuinfo_小米玄戒O1.prop` (已有) |
| GPU | ARM Immortalis-G925 | 需新增，Mali sysfs 路径 |
| 内核 | `6.6.77-android15-...` | 需新增，uname + /proc/version |

## 模块结构

```
xuanjie_o1/
├── xuanjie_o1.h      ← 所有伪造数据定义
├── xuanjie_o1.c      ← 合并 cpuinfo + gpuinfo + uname hook
└── Makefile
```

## 需要 hook 的系统调用

| 系统调用 | 用途 | 实现方式 |
|----------|------|----------|
| `openat` | 拦截 `/proc/cpuinfo`、GPU sysfs、`/proc/version` 的打开 | before: 路径匹配 → track fd |
| `read` | 返回伪造数据 | before: 根据 tracked fd 返回 fake_data |
| `close` | 清理 tracked fd | before: 清理记录 |
| `uname` | 伪造 `utsname.release` | after: 覆盖 release 字段 |

## 路径匹配表

```c
// /proc/cpuinfo — CPU 信息
{ "/proc/cpuinfo", ..., FAKE_CPUINFO_CONTENT, FAKE_CPUINFO_SIZE }

// /proc/version — 内核版本
{ "/proc/version", ..., FAKE_PROC_VERSION, FAKE_PROC_VERSION_SIZE }

// ARM Mali GPU 路径 — Immortalis-G925
{ "/sys/class/misc/mali0/device/gpuinfo",  ..., "Immortalis-G925", 17 }
{ "/sys/class/misc/mali0/device/gpu_model", ..., "Immortalis-G925", 17 }
{ "/sys/class/misc/mali/device/gpuinfo",    ..., "Immortalis-G925", 17 }
{ "/sys/class/misc/mali/device/gpu_model",  ..., "Immortalis-G925", 17 }
```

所有路径共用同一个 `find_path()` 匹配逻辑，每个 fd 存储各自的 `fake_data` 指针。

## 内核版本伪造

```
uname -r → "6.6.77-android15-00101-gXXXXXX"
/proc/version → "Linux version 6.6.77-android15-00101-gXXXXXX (build@ab8) ..."
```

`after_uname` 回调修改 `utsname.release`（偏移 130，65 字节）。

## 与现有模块的关系

- **替代** `cpuinfo_xuanjie_o1/` 和 `gpuinfo/`：一个模块搞定全部
- **独立目录**：不修改现有模块
- **CI 自动发现**：新目录有 Makefile，自动构建

## 修改的文件

| 操作 | 文件 |
|------|------|
| 新建 | `xuanjie_o1/xuanjie_o1.h` |
| 新建 | `xuanjie_o1/xuanjie_o1.c` |
| 新建 | `xuanjie_o1/Makefile` |

## 验证方式

```bash
cd xuanjie_o1 && make
kpatch $SUPERKEY kpm load xuanjie_o1_1.0.0.kpm

# CPU 伪装
cat /proc/cpuinfo          # → 玄戒O1 8核信息

# GPU 伪装
cat /sys/class/misc/mali0/device/gpuinfo  # → "Immortalis-G925"

# 内核版本伪装
uname -r                   # → "6.6.77-android15-..."
cat /proc/version          # → "Linux version 6.6.77-android15-..."

kpatch $SUPERKEY kpm unload xuanjie_o1
```
