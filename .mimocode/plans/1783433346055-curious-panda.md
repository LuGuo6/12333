# GPU 全面伪装 — 系统属性 hook 方案

## 目标

hook Android 系统属性读取，让设备信息App显示伪造的 GPU 信息。

## 需要伪造的属性

| 属性名 | 原值 | 伪造值 |
|--------|------|--------|
| `ro.board.gpu_vendor` | `higpu.v200` | `arm.mali` |
| `ro.hardware.egl` | `adreno` | `mali` |
| `ro.hardware.vulkan` | `adreno` | `mali` |
| `ro.gfx.driver.1` | `com.qualcomm.qti.gpudrivers...` | `com.arm.mali.drivers` |

## 实现方式

### Hook Android 属性系统

Android 属性读取通过两个函数完成：
1. `__system_property_find(name)` → 查找属性
2. `__system_property_read_callback(info, callback, cookie)` → 读取属性值

在 KPM 模块中 hook 这两个函数，当查询到目标属性名时，返回伪造的值。

### 关键步骤

1. **查找函数地址**：通过 `lookup_name()` 找到 `__system_property_find` 和 `__system_property_read_callback`
2. **Hook `__system_property_find`**：
   - before 回调：检查属性名是否为要伪造的属性
   - 如果是：修改属性值（直接覆盖属性结构体中的值字段）
   - 如果不是：不干预
3. **不需要 hook read_callback**：只要 find 返回的属性结构体中的值被修改了，后续的 read 自然会读到伪造值

### 属性结构体布局

```c
struct prop_info {
    unsigned int serial;        // 属性序列号
    unsigned int magic;         // 魔数
    unsigned int version;       // 版本
    char value[92];             // 属性值（固定 92 字节）
    char name[0];               // 属性名（紧随其后）
};
```

`__system_property_find` 返回 `prop_info*`，直接覆盖 `value` 字段即可。

## 验证方式

```bash
kpatch $SUPERKEY kpm load xuanjie_o1_1.0.0.kpm

# 验证属性伪造
getprop ro.board.gpu_vendor    # → arm.mali
getprop ro.hardware.egl        # → mali
getprop ro.hardware.vulkan     # → mali

# 验证设备信息App
打开设备信息App → GPU 信息应显示 ARM Mali
```
